# 가에 및 연계 변경 — 3.0.0-remake.2

가에 캐릭터는 순수 데이터와 기존 공통 전투 모듈을 사용한다. CommandFeatureService는 명령 모드·일회성 회복·원격 표시만 담당하며 일반 스테미나를 덮어쓰지 않는다. AttackFeatureTransformService의 modular-laser 프로필이 선택된 공통 적중 모듈/연사속도/색상 팔레트를 조합한다. 캐릭터 ID 분기는 없다.

| 항목 | 현재 동작 |
|---|---|
| 기본 평타 | 레이저 활성화, 피해150, 비용150, 쿨600ms |
| ACCELERATE | 평타 연사1.4배, 쿨600/1.4ms; 스킬/반격/이동속도 변경 없음 |
| FIX | 잃은체력25% 회복, 부족 체력까지만; 명령 표시1초 녹색 표시(글로우 없음) |
| KNOCKBACK | 평타 적중 넉백 거리160/속도12 |
| ELECTRIC | 평타 ZAP1000ms, 각 발사의 레이저 색 고정 주황색 |
| 스킬 방전 | 선딜500ms, 범위190, 피해150, 넉백160, DISCHARGE1000ms, 비용200/쿨700ms |
| 반격 | 기존 원형 피해150/범위180 및 무력화 넉백, 이후 무적·자기 기절2000ms; 스테미나 비례 없음 |
| UI | 윗줄 KNOCKBACK/ACCELERATE/FIX/ELECTRIC, 아랫줄 DUAL/PIERCE/INSTANT/WIDE/RANGE |
| 입력 | 명령 문자열이 완성되는 마지막 글자에서 실행하고 닫기; 틀린 문자열은 수정 가능 |

FIX 원격 사건은 표시만 재생하며 회복을 중복 실행하지 않는다. 상태형 기능은 기존 feature-state 및 snapshot으로 복제한다. 레이저 옵션은 투사체형과 INSTANT 모두 같은 적중 모듈을 적용한다. 과열/COOLING/REPAIR 명령과 스테미나 충전/차감 예외를 제거했다. /laser는 기본 활성 상태를 확인하는 호환 명령으로 남겼다.

반 스킬 기절과 반격 기절을 제거하고 반격은 공통 무력화 넉백84/속도10을 사용한다. 스패너 정상 재생25/초, 기존 파괴 수리 정책/시간은 유지. 레테 LMB 비용350. 체리티 차징 LMB 탄속52; 별도 즉발 공격은 유지.

검증: test-gae.cjs 9개 그룹(초기화/자원, 회복·원격 표시, 연사 비율·재변환, 투사체/즉시 적중 옵션·색, 자동 입력, 수치/CC, Canvas 호출로 정렬·1초 녹색 표시 및 글로우 없음, 실제500ms 실행·쿨다운·설명 순서), 구조14·테르디온28·게임15·방17. build/docs/check/verify/runtime 구문 검사. 실제 브라우저·두 기기 온라인 전투는 미검증.

Ctrl+W: 일반 탭에서는 사이트가 브라우저 예약 단축키를 보장 차단할 수 없다. Keyboard Lock은 JavaScript로 실행한 전체화면, 지원 브라우저, 권한이 필요하다. 현재 일반 탭 실행 방식에는 가짜 차단을 넣지 않았다. 참고: https://developer.chrome.com/articles/keyboard-lock

추가 수정: 반 RMB 비용200. 가에 설명은 LMB/RMB/L-Shift 다음 명령 표시 순서. 공격 전 timing.delay의 requireAttackId 조건을 제거하고 preview.create로500ms 선딜과 쿨다운 검사를 연결한다. ELECTRIC 레이저의 모든 층은 RGB255,145,35. 실제 실행499ms 미발동/500ms 발동과 쿨다운 차단 회귀 검사 포함.

반 후속 변경(3.0.0-game.9): 정상 내구도 재생25/초. 파괴 후 시간 수리는 제거하고 직접 적중5회로800 복구. 소환수/훈련봇 및 DOT 제외.

3.0.0-balance.2: 현재 반 정상 회복25/초·파괴 후 직접 적중5회 복구.

3.0.0-game.10: 반 스패너 내구도 완전 흡수 시에도 적중 효과 정상 적용. 파괴 후5회 복구 유지.
